# ADDRESS_BOOK


A simple Contact Management System developed using C.

## Procedure



1. Initialize Address Book
   Load existing contacts from the file when the program starts.

2. Create Contact
   Enter the name, phone number, and email ID.
   Validate all details before saving the contact.

3. List Contacts
   Display all stored contacts with their name, phone number, and email ID.

4. Search Contact
   Search for a contact using:

   * Name
   * Phone Number
   * Email ID

5. Edit Contact
   Select a contact and update its:

   * Name
   * Phone Number
   * Email ID

6. Delete Contact
   Select a contact, confirm deletion, and remove it from the address book.

7. Save Contacts
   Store the updated contact details into a file before exiting.
